GARAKLAND v3.1 쿠폰에서 구글 지도 길찾기 (Windows)

1. ZIP 압축을 모두 해제합니다.
2. Python 3.10 이상 설치 후 start_windows.bat을 더블클릭합니다.
3. PC나 휴대폰 브라우저에서 실행된 사이트를 엽니다. (기본 주소: http://localhost:8769)
4. 좌측 또는 하단의 [🎟 쿠폰 지갑]을 누릅니다.
5. [쿠폰 받기]를 누르면 [매장으로 길안내] 창이 자동 나타납니다.
6. [🚶 도보 ... 길안내 열기]를 누르면 Google 지도 앱/웹이 새 화면에서 열립니다.
7. 이미 받은 쿠폰은 [내 쿠폰 지갑]에서 쿠폰번호를 눌러 다시 길안내를 열거나 [🧭 길찾기]를 바로 누릅니다.
8. 실제 할인 적용은 매장 상인이 번호를 확인하고 기존 [상인 관리실 > 쿠폰 사용 처리]에서 승인해야 합니다.

* 시연 가상 매장은 실제 매장이 아니므로 안내 목적지는 '가락시장'입니다.
* 실제 점포의 검증된 좌표가 등록돼야 해당 매장 GPS로 직접 길찾기 합니다.
* 주소·층·호실 정보는 별도로 확인하세요. 실내 호실까지의 Google 자동 길안내는 보장되지 않습니다.
* Google 외부 길찾기 링크 자체에는 API 키가 필요 없습니다.
* 네이티브 지도 실행과 실제 경로 정확도는 스마트폰 현장 테스트가 필요합니다.

전체 기능 테스트: verify_windows.bat (Node.js 설치 시 지도 URL 테스트까지 실행)

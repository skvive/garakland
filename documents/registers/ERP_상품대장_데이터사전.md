# ERP 상품대장 데이터 사전 (가락랜드 v6)

* 모든 업로드 항목은 **비공개 초안**이며, 고객 사이트로 자동 게시되지 않습니다.
* UTF-8 또는 UTF-8 BOM CSV / 헤더 9개를 고정 순서로 입력합니다.
* `product_code`: 영문·숫자·`-`·`_` 1~60자, 업로드 파일 내 중복 금지.
* `shop_id`: 이미 등록된 매장 ID. 실존 점포의 사업자·GPS 검증과 구분.
* `product_name`: 한글 상품명 1~100자. AI 생성 문구라도 상인 최종 승인 필요.
* `unit`: 팩/상자/kg 등 상품 규격.
* `regular_price`, `special_price`: 정수 원, 100~100,000,000; 특가 ≤ 정상가.
* `stock`: 0~1,000,000개. 재고는 매장 담당자가 확정해야 합니다.
* `starts_at`, `ends_at`: ISO 8601, 예: 2026-10-29T09:00:00+09:00. 기간 최대 1년.
* 서버는 CSV 전체를 검증한 후 거래 단위로 저장합니다. 오류가 있으면 **전체가 등록되지 않습니다.**
* API: `/api/v6/products/validate` → `/api/v6/products/import`, 둘 다 관리자 토큰 필수.
* 실제 매장 등록은 기존 `/map.html`의 관리자 점포 등록 기능에서 별도로 수행합니다.
* 실제 매출이 아닌 테스트 장부는 `/api/v6/settlement`에서만 별도로 조회합니다.

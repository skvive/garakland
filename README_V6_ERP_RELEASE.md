# 가락랜드 ERP RELEASE v6.0 — 상용 준비 운영센터 · UI 정밀검수판

**버전:** 2026.10.29 / 현장·법무·결제 계약 전 검증 베타. 실제 가락시장 공식 서비스, 승인된 상인회 사업, 유료 상품권 또는 상용 결제 시스템이 아닙니다.

## Windows 실행

1. ZIP 전체를 압축 해제하고 Python 3.10 이상을 설치합니다.
2. **`start_erp_windows.bat`** 실행 → `http://localhost:8769/ops.html`을 엽니다.
3. 콘솔에 나오는 **관리자 토큰**을 ERP 인증에 입력합니다. 이 토큰은 타인에게 공개하지 않습니다.
4. 고객 특가 `http://localhost:8769/market.html`, AR 안내 `http://localhost:8769/`, 지도 `http://localhost:8769/map.html`로 접근합니다.
5. `http://localhost:8769/documents.html`에서 상인 관련 Word 서류 5종을 내려받습니다.
6. 테스트: `python -m unittest tests.test_erp_v6 tests.test_growth_v5 tests.test_beta tests.test_marketing_adapters -v` / Node 설치 시 `node tests/test_navigation.mjs`.

## v6에서 변경한 내용

- **페이지별 시각 디자인:** `assets/v6/market-hero.webp` 텍스트 없는 AI 생성 사진을 추가해 배경 사진 내 잘못된 한글 간판을 방지했습니다. 시장 관련 안내 문구를 HTML 텍스트로 표시하고 `market.html` 메인 카피·길찾기 표현·상품권 명칭을 다듬었습니다. AI 이미지는 실제 점포 증빙이 아니라고 명시합니다.
- **ERP 신규 대시보드 (`ops.html`):** 6개 화면(출시 현황, 업무 보드, 상인 서류, 상품 ERP, 모의 정산, 최종 검수). `ops/app.js`, `ops/style.css`.
- **업무 보드:** HTML5 drag/drop, 서버에 카드 단계/순서 저장. 모바일은 키보드/단계선택 방식 제공.
- **서류 관리:** 점포별 필수서류 8종 검토 단계·증빙 참조번호와 감사기록. 실제 문서 본문/민감한 고객 개인정보는 이 DB에 저장하지 않습니다. '내부 확인'은 법적 인허가를 대신하지 않습니다.
- **상품 ERP:** CSV 끌어놓기/선택 → 서버 검증(점포·가격·기간·중복·수량·UTF-8 BOM) → 일괄 비공개 초안 등록. 일부 오류 시 전체 반려, 고객 화면 자동 노출 없음.
- **모의 정산:** 기존 v5 상품권 시연 원장을 조회·CSV 내려받기. 실제 매출액·송금·정산은 **0원**, 실제 결제 구현/개통 없음.
- **운영 문서:** `documents/templates/`에 Word 실무 양식 5종, `documents/registers/`에 CSV 양식과 데이터 사전. 브라우저 문서 안내 `documents.html`.
- **인코딩 보완:** 서버 HTML/CSS/JS 응답에 `charset=utf-8`를 포함해 한글 깨짐 가능성을 줄였습니다.
- **이전 기능 보존:** 기존 v5 쿠폰 발급·사용 처리, GPS 길찾기, AR·3D 지도 코드, 가상 주문, 광고 동의·모의 발송·상품권 잔액 원장을 보존합니다.

## 테스트·한계

- Python 서버·ERP API·기존 베타 회귀 **57개 테스트 통과**: `docs/v6/final-python-tests.log`.
- 추가 v6 ERP API만의 통합 검사는 20개 통과: `docs/v6/erp-integration.log`.
- 실제 Chromium 브라우저에서 ERP 6개 화면 × PC 1440px/모바일 390px 화면을 확인하고 스크린샷 12종 저장: `docs/v6/screens/`. PC 실제 카드 드래그·상태 변경·증빙 저장·CSV 등록 흐름은 1차 종단 검증 통과. 모바일의 카드 선택 기반 상태 변경은 검증했으며 실터치 drag 제스처는 지원하지 않아 단계 선택 방식을 제공합니다. 장시간 브라우저 재검사는 실행 환경에서 중단되어 전체 통과로 기재하지 않습니다.
- 문서 5종은 Word에서 렌더링한 **각 1페이지**를 이미지 검수했습니다.
- 실제 Google 3D API 렌더링·현장 스마트폰 GPS·실점포 좌표·카카오/SMS/SMTP 실발송·실제 상품권 결제·환불·정산·공식 참여 계약은 **완료되지 않았습니다.**

## 미검증 또는 미구현 — 고객에게 완료로 안내 금지

1. 이 환경의 실제 로컬 `http://` 접속이 Chromium에서 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어, **실서버를 연결한 브라우저 end-to-end 테스트를 수행하지 못함**. API와 DOM/UI를 분리해 검증함.
2. iOS Safari·Android Chrome 카메라·QR·GPS·네이티브 BarcodeDetector 실제 장치 테스트를 못함. 미지원 기기는 수동 입력과 사진 업로드를 사용함.
3. Google 3D 실제 지도 키/결제 없이 브라우저/GPU 렌더 테스트 불가. V2 코드로 유지, 정확한 매장 GPS가 없어 실제 핀이 없음.
4. 실제 가락시장 전수 점포·층별 호실 좌표·실매장 메뉴판·판매 가격·계약된 블로그/배달 서비스 미확보. **4개 시연점은 허구**이며 정확한 시장 내부 위치라 주장하지 않음.
5. 사진 인식은 ORB 등록 기준 사진 매칭. **포켓몬 GO급 실물 객체 인식·AR world tracking·SLAM·실내 위치추적 미구현**. 현재 AR은 카메라 위 HUD 오버레이.
6. 익명 쿠키를 삭제하면 쿠폰/스탬프 식별이 달라질 수 있음. GPS/QR 위변조 방지는 제한적이며 악용, 재발행, 인증 지연, 기지국 음영에 대한 실제 환경 부하테스트 필요.
7. 실제 배송·배달앱 주문 접수·결제·환불·주문 체결·고객과 판매자 통신은 아직 연동 안 됨. 현재 주문은 데이터베이스 **시연 요청** 저장만 수행.
8. 인증 방식은 상용 회원제 아닌 임시 세션·상인 키. 개인별 계정과 권한, 관리자 콘솔 접근 감사, 서버 보안 스캔, DB 마이그레이션, 백업·복구·재해복구 테스트 필요.
9. 위치기반서비스 사업/개인정보 처리의 법률·약관·방문 행사 혜택 규정 및 보험·안전 검토 필요.

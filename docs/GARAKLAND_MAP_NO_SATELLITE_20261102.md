# Garakland – 위성 탭 제거 / 3D 우선 UI
- 사진 증상: 위성 타일에 '이미지가 없습니다'가 반복적으로 표시되는 화면.
- 수정: 위성 전환 탭 삭제, 지원 UI 모드는 모식도/지형/3D/층별.
- 3D 연결 성공 시 3D 표시, 연동 실패 시 시연용 모식도로 안전하게 복귀. 위성으로 자동 복귀하는 코드 제거.
- 지도 엔진은 satellite 타입을 외부에서 호출해도 명시적으로 거부.
- Google Maps 연결 설정의 위성 설명 삭제, 4개 탭 반응형 최소 터치 크기 확보.
- 기존 실내지도, 매장/지형/3D/관리자 DB 및 위치 기능은 유지.
- 테스트: tests/test_map_mode_policy.py; tests/browser_map_mode_qa.py, GitHub Actions.
- 사용자 요청은 탭 제거이며 Google 3D의 사진 기반 텍스처 사용을 중단하는 뜻은 아님.

# 가락랜드 | 롯데월드 다음 코스 캠페인 V2 디자인 검수 기록

기준일: 2026-11-02 / 운영 사이트: https://garakland.lexid.site/lotteworld-next.html

## 기존 문제
1. 기존 3D 바닥 모양과 단독 캐릭터 위주 히어로는 실제 방문 분위기를 전달하기 어려움.
2. 잠실에서 이동 후 무엇을 즐기는지 핵심 정보가 아래에 분산되어 설득력이 떨어짐.
3. 층별 지도와 교통 길찾기가 서로 분리되어 방문 전 탐색 동선이 불명확함.
4. 롯데월드 이미지·로고·마스코트 사용권이 검증되지 않아 마케팅 허위 제휴 인상과 권리 침해 가능성 관리 필요.

## V2 개선
- 원본 가락한상 캐릭터를 헤더·가이드에 유지. AI 생성 콘셉트 장면은 시각적 스토리텔링에만 사용하고 실제 시설 사진처럼 표시하지 않음.
- 상단 첫 화면에 **롯데월드 다음 코스, 가락랜드!** 카피 + 8호선 안내 + 실내지도 CTA + 이동정보 제공.
- 실제 수치 없는 과장 문구(소요시간·할인율·제휴혜택)를 제거. 교통앱 링크로 실시간 정보 확인 유도.
- ‘잠실역 → 가락시장역 → 가락랜드’ 3단계 이동 정보를 독립 블록으로 배치.
- 수산(1F)·채소/과일(B1)·식당가(3F) 실내지도 딥링크.
- 모바일(360/390), 태블릿(768), PC(1440)에 대응하는 반응형 그리드, 표기 대비, lazy-loading, 이미지 SEO/OG 구성.
- 생성 이미지 데스크톱 194KB, 모바일 116KB로 최적화. 원본 포함 홍보자료는 Drive 저장.
- 안내 문구에 공식 제휴/쿠폰 여부, 영업 여부 확인 필요, 실내지도 개략 모델 제한을 기재.

## 권리 및 사실 표기 주의
이 캠페인은 **가락랜드 독립 관광 코스 제안**이다. 롯데월드 로티/로리, 공식 로고, 공식 홍보 이미지, 마스코트 유사물을 홈페이지에서 사용하지 않는다. 생성 이미지의 놀이공원은 개념적 배경이며 특정 시설의 건물·입장권·혜택을 사실처럼 광고하지 않는다.

AI 생성 이미지와 일부 마스코트 캐릭터의 표현이 실제 시설 사진을 대체하지 않도록 별도 설명을 적용. 구역, 점포명, 영업시간/가격, 소요시간, 정확 실내 길찾기 안내는 실증되지 않은 경우 확인 필요로 구분.

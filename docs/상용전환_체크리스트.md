# 실제 매장/배달 서비스 전환 단계

- [ ] 서울시농수산식품공사와 점포대장/호실/배치도 제공 범위와 사용권 협의.
- [ ] GPS 정확도·출입구·건물 레벨·실내 층별 지도/엘리베이터 동선 현장측량.
- [ ] 상인 가입/매장 소유자 검증과 사진·메뉴·쿠폰 발행 권한 약관.
- [ ] 매장별 최소 5~15장 기준 사진, 시기/조명/각도/가림 변형 인식 테스트, 오탐률 목표 결정.
- [ ] AR 카메라/UI 및 OCR, QR, 원근 추적 실제 기종별(iOS/Android) 접근성 검사.
- [ ] Google Maps 키 비밀 관리, HTTP 리퍼러/API 제한, 콘솔 청구 예산·쿼터 설정, 표기 의무.
- [ ] 정식 로그인/회원가입, 회원 쿠폰 지갑 지속성, 다중 단말 동기화.
- [ ] 악성 GPS 앱·QR 중계/재사용/매장 자체 쿠폰 남용 탐지 및 분쟁 처리.
- [ ] 개인정보 위치정보 업무 분석: 목적, 보유기간, 위치기반서비스 고지/신고 등 전문 법률 검토.
- [ ] 배달 플랫폼 상점 개별 공식 URL 허용범위 검증·제휴/비즈니스 API 사용 계약.
- [ ] 주문 예약/결제/정산/환불/배달 SLA·과금/고객센터 구축 및 보안성 진단.
- [ ] 공공시장 안전장소 규정, 상·하차/시장 통로 위험 행동 방지, AR 보행 주의 안내.
- [ ] 광고선배치 시 스폰서 표기와 추천·광고 구분, 청소년 보호 등 검수.
- [ ] 실내 길찾기는 GPS만으로 미구현. BLE/Wi-Fi RTT/UWB/비주얼 포지셔닝 검토.

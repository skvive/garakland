## Chromium HTML/CSS/JavaScript 검사

- 환경: 1440×900 데스크톱, 390×844 모바일.
- 테스트 범위: 관리자 화면 진입, 12개 모듈 표시, 검색 필터, 모듈 토글, 검수 작업 생성·실행, 반응형 폭, 화면 JS 예외.
- 결과: 두 viewport 모두 `pageerror=[]`, `document.documentElement.scrollWidth <= window.innerWidth`, 클릭 흐름 통과.
- 브라우저 제약: 테스트 런타임 Chromium에서 모든 URL 이동이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 거부되어 **HTML/CSS/JS는 오프라인 렌더링, API는 모의 응답**으로 테스트했다. 서버 실제 API는 별도 Python HTTP 통합 테스트로 검증했으며, 브라우저에서 서버까지 종단간 네트워크 연결은 검증하지 못했다.
- 발견 후 수정: 인증 성공 후 `locked` 안내 패널이 `display:flex` CSS에 의해 남는 오류 → `[hidden]{display:none!important}` 교정. 작업 수동 실행 후 목록이 이전 스냅샷으로 덮이는 오류 → `jobs()` 재조회 추가. 모바일 영웅 배너 캐릭터와 카피 중첩 → 배치 조정.

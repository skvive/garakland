# 조사 근거 · 오픈소스 · 브랜드/라이선스

- [Google Maps JavaScript 3D 공식 개요](https://developers.google.com/maps/documentation/javascript/3d/overview): 실제 3D 항공 기반 지도의 Google JS API 선택; Google 지도 사용량/결제/3D 영역 커버리지 별도 확인.
- [Google Maps JavaScript API 가격](https://developers.google.com/maps/documentation/javascript/usage-and-billing): 클라우드 결제 계정 및 API 키 필요, 2D/3D 사용량 과금.
- [Google Maps JS API 정책](https://developers.google.com/maps/documentation/javascript/policies): 지도 출처 명시/제한 준수; 이미지/장소 정보 무단 재배포 금지.
- [MDN BarcodeDetector](https://developer.mozilla.org/en-US/docs/Web/API/BarcodeDetector): QR 네이티브 읽기, 미지원 브라우저 존재, 보안 컨텍스트 필요.
- [MindAR / hiukim/mind-ar-js](https://github.com/hiukim/mind-ar-js): MIT 라이선스, 등록 타깃 이미지 추적을 위한 상용 고도화 후보. **이 베타에서 해당 엔진을 실행하는 것은 아님.**
- [AR.js / AR-js-org/AR.js](https://github.com/AR-js-org/AR.js): MIT (일부 하위 의존성 LGPL 등 추가 조건 확인), 위치·표식 AR 후보.
- [LocAR.js](https://github.com/AR-js-org/locar.js): MIT, GPS 기반 AR 후보. 실내 GPS 정밀도 한계 검토 필요.
- [OpenCV](https://opencv.org/): ORB/BFMatcher/RANSAC 사진 특징점 대조. OpenCV 라이선스 별도 확인. `opencv-python-headless` 패키지 선택 설치.
- [서울시농수산식품공사](https://www.garak.co.kr/): 실제 상점/배치정보는 공식 소스의 권한·최신성·허가를 확인 후 등록.

## 독창성과 저작권

캐릭터·몬스터·포켓볼·포켓몬 명칭이나 이미지, 디즈니/롯데월드의 보호되는 일러스트/브랜드 자산을 사용하지 않았습니다. 포켓몬 GO의 **탐색·도보 방문·수집/미션·AR 상호작용**이라는 일반적인 놀이 패턴만 벤치마킹했습니다. 데모에 사용된 4개 매장과 간판/메뉴 사진은 프로그램으로 새로 제작한 창작 시연 에셋이며 실제 상인과 무관합니다. Google Maps의 실제 위성/지형 이미지는 ZIP으로 다운로드하지 않았습니다. 지도는 사용자가 자신의 API 키로 연결할 때 Google의 라이브 서비스가 표시됩니다.

가락시장 실점포 사진·메뉴판·블로그 홍보문서·배달 URL은 각 상인의 명시적 등록 및 이용권한 확인이 필요합니다. 위치정보 수집·이용은 이용자 동의 및 관련 법령 전문 검토 후 서비스하세요.

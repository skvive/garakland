## 의도적인 미구현/허위 기능 방지

- 실제 상호나 판매 가격으로 오해될 수 있는 데이터는 모두 시연 자료라고 표시.
- 좌표 미검증 매장은 가락시장 대표 주소로만 Google 길찾기.
- 선불 상품권 충전·실제 광고 발송 및 실결제 불가 표시.
- 사용자 제공 캐릭터 원본 및 브랜드 원본 파일을 보존하되 등록 가능성을 단정하지 않음.
- AI 사진은 실제 점포 사진으로 표시하지 않음.

## 개선 권고 순서

1. 운영기관·상인회와 실점포 데이터 수집 계약 및 최신 전수조사.
2. 실제 동·층·호실 GPS와 실내 지도 데이터 확보 및 검증 필드 구축.
3. 점포 블로그 CMS·메뉴 이미지·운영시간/정산·광고 동의 등의 운영 도구와 브랜드 사이트를 하나의 인증 세션으로 통합.
4. Google 지도 및 AR GPS의 실기기 외부 API 검증, 개인정보처리방침·동의 화면과 결제 보안 검수.
5. 정교한 모바일 검색 자동완성·지역 행사 알림·다국어·접근성 스크린리더 테스트.

## 테스트 방법의 한계

브라우저 환경에서 URL 직접 탐색이 관리자 정책으로 차단되어 Playwright `set_content()` 방식으로 HTML/JS/CSS 및 실제 이미지 Data URI를 삽입해 렌더링했습니다. 이는 **클라이언트 화면·상호작용 검사**이지만 운영 URL·외부 API E2E 검사는 아닙니다. 별도로 로컬 HTTP 서버 및 Python 단위·통합 테스트 수행.

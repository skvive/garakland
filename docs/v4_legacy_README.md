# GARAKLAND v3.1 — 쿠폰 누르면 Google 지도 길안내

**v3.0 AR QUEST 베타 기반 기능 추가 버전**

## 단순 사용방법
1. `start_windows.bat` 실행 후 브라우저에서 `http://localhost:8769` 접속
2. **🎟️ 쿠폰 지갑** 선택 → **쿠폰 받기** 선택
3. 자동으로 뜨는 창의 **🚶 도보 Google 지도 길안내 열기** 선택
4. 쿠폰을 이미 받았다면 **내 쿠폰 지갑**에서 쿠폰 번호 표를 누르거나 **🧭 길찾기**를 직접 선택
5. 상인은 **상인 관리실 > 쿠폰 사용 처리**에서 고객에게 제시받은 10자리 코드를 확인

> 가상 시연 매장에는 실제 좌표가 없습니다. 시연 카드에서는 가락시장까지 가는 경로만 연결하며, 실매장 방문·결제·할인은 되지 않습니다.

## 실제 점포를 정확히 안내하려면
`data/shops.template.csv`의 실제 점포명·건물·층·호실·위도·경도·검증 상태를 작성하고 **관리자 인증을 거쳐 기존 점포 등록 API로 임포트**하십시오. 검증된 실매장에만 개별 GPS 길찾기가 활성화됩니다. Google 지도는 실내 층·호실까지의 경로를 보장하지 않습니다.

- 상세 연동/검수 기준: [docs/COUPON_GOOGLE_NAV_3_1.md](docs/COUPON_GOOGLE_NAV_3_1.md)
- 기존 AR/쿠폰/관리/주문 기능은 동일하게 유지합니다.
- Google 지도 앱 외부 길찾기에는 API 키가 필요 없습니다. 내장 3D 지도에는 별도의 Google Maps 설정이 필요합니다.

# GARAKLAND AR QUEST v3.0 Beta — 위치 기반 시장 탐험·쿠폰·메뉴/주문 연동

**제작일: 2026-10-29 | 독립 가락시장 디지털 테마파크 기술 시연 | 실제 거래·위치 인증 상용 서비스 아님**

## Windows 실행

1. ZIP을 원하는 폴더에 모두 압축 해제합니다.
2. Windows PC에 **Python 3.10 이상**을 설치합니다. `start_windows.bat`을 더블클릭하면 `http://localhost:8769`가 열립니다.
3. 홈 → **AR 탐험** → **카메라 탐험 시작**을 누릅니다. 카메라 접근이 안 되더라도 아래 **매장 ID 직접 입력**에 `GARAKLAND:demo-sea`를 넣어 체험할 수 있습니다.
4. `assets/demo/sea-poster.png`를 다른 기기의 화면에 띄워 QR로 비추거나, 스캔 화면에서 이 이미지를 업로드하면 매장 정보를 확인합니다. **이미지 업로드/촬영 사진에서 자동으로 간판을 판별하려면** `install_vision_windows.bat`으로 OpenCV+NumPy+Pillow를 설치하고 서버를 재실행하세요.
5. 매장 상세 화면에서 샘플 메뉴판·가격·쿠폰을 볼 수 있으며, **시연 스탬프 획득** → 미션 배지 → 쿠폰 발급 → 포장·배달 요청 시연을 경험할 수 있습니다.
6. **상인 관리실**에서 실행 창에 표시된 관리자 토큰을 넣고, 매장 선택 → **상인 키 발급** → 새 쿠폰 발행·3분 현장 QR·쿠폰 사용·매장 홍보 URL·사진 등록을 시험합니다.
7. **지도·매장 찾기 → Google 위성·지형·3D 지도**는 기존 Google Maps v2 화면(`/map.html`)으로 연결됩니다. API 키, 승인 도면, 상점 실측 좌표가 없으면 Google 3D/정확한 매장 핀은 나타나지 않습니다.

**중요:** Windows PC에서 `localhost` 카메라 접근은 일반적으로 가능합니다. **휴대전화로 PC 서버에 LAN IP로 접속하면 카메라/GPS가 HTTP에서 차단될 수 있으므로 HTTPS 도메인·인증서가 필요**합니다. `index.html`을 더블클릭하는 `file://` 실행으로는 백엔드의 쿠폰·방문 인증·데이터 저장이 동작하지 않습니다.

## 게임 플레이

- 지도에서 목적지를 찾아 카메라로 매장 현장 표식을 발견 → **실제 점포의 GPS가 검증됐고 시간제 QR+위치가 일치하는 경우** 40XP와 스탬프를 하루 한 번 획득합니다.
- 3개 서로 다른 매장, 총 5번 방문, 3일 연속 등의 컬렉션을 달성합니다.
- 시연 매장은 위치 인증 없이 데모 전용 스탬프로 교육용 플레이를 할 수 있습니다. **현실 방문을 증명하는 기록이 아닙니다.**
- 쿠폰은 캠페인별 하루/ISO 주간/1회 단위로 자동 갱신되며, 회차 재고가 소진되거나 중복이면 발행 거부됩니다. 상인 키가 있어야 사용 처리가 됩니다.

## 점포 및 이미지 등록

- `/map.html`의 관리자 화면에서 기존 `data/shops.template.csv`에 맞게 점포 대장 CSV를 올립니다. `coordinateStatus=verified`로 처리하려면 현장 측량·출입구 좌표 검증이 필요합니다. 위성지도 클릭만으로 검증 처리를 하지 마세요.
- AR 홈의 **상인 관리실**에서 점포를 선택하고 블로그·공식 주문 URL, **메뉴명|숫자가격** 양식, 간판 기준 사진·메뉴판 사진·히어로 이미지를 올립니다. 이미지 등록은 Pillow가 필요하며, 사진 대조는 OpenCV가 필요합니다.
- 고해상도 점포 간판 사진은 정면/조도/가림/계절·리뉴얼별 여러 장을 관리하는 상용 확장이 권장됩니다. 베타는 점포당 최근 기준 사진 1장 지원입니다.
- `assets/demo`의 4개 시연점은 **모두 가상 매장**이며 실제 상호/좌표/메뉴/가격이 아닙니다.

## 서버·보안

- Python 표준 라이브러리 HTTP 서버, SQLite, 랜덤 세션 식별 쿠키(`HttpOnly`, `SameSite=Lax`), 상인 비밀키 SHA256 저장, 관리자 토큰, 서명된 만료 QR, 캠페인 재고 SQLite `BEGIN IMMEDIATE` 동시성 잠금, 쿠폰 중복/재사용 차단, 이미지 포맷/크기 검사.
- 원시 GPS 좌표는 DB에 영구 저장하지 않습니다. 방문 기록에는 점포 ID·날짜·유형만 남깁니다. 사진은 대조 요청 한 장만 전송하며 **기준 사진으로 등록된 파일은** 서버에 저장됩니다.
- 관리자 토큰은 실행 콘솔에서 확인하거나 `GARAK_ADMIN_TOKEN` 환경변수로 직접 설정합니다. 미설정 시 매 실행마다 새 토큰이 발급됩니다.
- 기본 서버 바인딩은 **127.0.0.1**입니다. 인터넷에 포트를 직접 공개하지 마세요. 상용 서비스는 TLS/역방향 프록시, 사용자 계정·권한, 위변조 방어, 정식 위치정보 약관, 보관주기·삭제 처리, 모니터링·감사 로그가 추가로 필요합니다.

## 설치 옵션

서버 기본 기능은 Python 표준 라이브러리로 작동합니다. 사진 대조·사진 업로드·동적 QR 이미지를 위해 `install_vision_windows.bat` 또는 `python -m pip install -r requirements-optional.txt`를 실행하세요. QR 이미지 라이브러리가 없으면 시간제 QR **문자열은 발급**되지만 PNG 이미지는 생성되지 않습니다.

테스트:

```bash
python -m unittest discover -s tests -v
```

## 상용 운영에 특히 중요한 조건

1. 가락시장 실제 점포대장·현장 좌표·실내 안내 도면 및 사용권, 점포별 블로그·이미지·메뉴의 소유자 승인.
2. 위치정보 처리 및 광고·쿠폰 발행 약관, 개인정보보호 등 관계법 검토. GPS는 건물 내부에서 불안정하므로 **단독 GPS 인증에 의존하지 말고** 상인 서명 QR+현장 확인 방식을 검토.
3. 공식 배달앱 연동 계약/API 제공 여부 확인 및 결제·환불·배송 책임자 지정. 이 베타는 **실제 주문·배달 기능을 제공하지 않습니다.**
4. 실사 AR 구현 시 이미지 타깃 `.mind`/AR.js·LocAR 등을 별도로 연동, iOS/Android 실기기 검수. 포켓몬 GO와의 제휴/공식 관계 없음.
5. Google Maps 데이터/항공영상 임의 다운로드·재배포/무단 객체 인식 사용 금지. v2는 Google JS 라이브 API를 통해 표시.

자세한 구현·한계·출처는 `docs/`를 보세요.

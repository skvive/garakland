[통과]
- 기존 서버 통합 테스트: 12 / 12
- Google Maps 길찾기 URL 단위 테스트: 통과 (GPS 검증 / 미검증 / 시연 / 누락 / 잘못된 좌표 / 이동수단)
- 브라우저(오프라인 모의 API) 데스크톱 1440px: 쿠폰 수령, 안내창, 쿠폰 지갑, Google 길찾기 URL, 가로 넘침 점검 통과
- 브라우저(오프라인 모의 API) 모바일 390px: 위 동일 통과
- Google Maps URL 모듈 정적 파일 HTTP 응답: 200 text/javascript
- JavaScript 문법 검사: 통과
- 쿠폰 클릭 시 사용 처리되지 않으며 상인 확인 과정이 별도로 유지됨
- 확인된 실매장 GPS의 정확한 매장 목적지 연결과 가상/미검증 매장의 가락시장 공통 목적지 분리 확인

[미검증 및 한계]
- 외부 Google Maps 웹/앱 실제 실행: 검수 환경의 외부·로컬 브라우저 네트워크 제한으로 수행하지 못함
- 실매장 현장 GPS 좌표: 전수 점포 좌표 자료 미확보
- Google 지도 내비게이션 음성 안내 및 호실까지 실내 길찾기: 별도 현장 및 기기 확인 필요
- 운영 상점 쿠폰 유효성: 제휴·본인 인증, 실제 상인 승인 등 추가 검증 필요
- Google 내장 3D 지도: 기존 버전의 Maps JS API 키 필요

[실제 데이터 입력]
1) 점포 ID, 매장명, 건물, 층, 호실, 좌표를 공식 자료로 확인
2) 관리자 인증된 점포 등록 API를 사용하여 coordinateStatus=verified로 저장
3) 쿠폰이 해당 점포 ID를 가리키는지 확인
4) 실기기에서 사용자의 현재 위치→점포 GPS 안내를 검수
5) 실내 층·호실 안내는 현장 확인 후 연결

공식 URL 사양: https://developers.google.com/maps/documentation/urls/get-started

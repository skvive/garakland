# 가락랜드 모바일 층별지도·매장 검색 연동 (P1·P2)
- GitHub 작업 브랜치: `feature/garakland-indoor-map-20261102`, 원본 master 보존
- 휴대폰: 지도 1.0~4.0배 확대·축소·초기화, 포인터·터치 두 손가락 확대, 드래그 이동, 키보드 확대(±/0) 및 화살표 이동

# GARAKLAND AR QUEST 3.0 — 테마파크형 위치기반 플랫폼 제품기획서

## 비전과 사용자 흐름

**주 타깃:** 가락시장 방문객·수산/청과/축산 구매자, 가족 탐방객, 상인, 상점 콘텐츠 제작자. **차별점:** 단순 점포 지도에 현장 발견·게임 보상·상인 홍보·쿠폰·주문 의향을 추가.

### 핵심 동선

1. Google 3D/위성/테마파크 안내 지도에서 관심 매장과 업종을 선택한다.
2. 현장 도착 → 카메라 촬영/QR 스캔 → 서버에서 등록된 점포 사진 특징점/QR 정보를 매칭한다.
3. 스마트폰 화면에 매장 이름·베스트 메뉴·쿠폰 미리보기가 겹쳐 나타난다. **현재 구현은 카메라 HUD 오버레이**이지 정밀 3차원 앵커가 아니다.
4. 상세 메뉴판 사진→ 매장 블로그 새 탭 → 상점과 상담 또는 정식 제휴앱 링크로 이동한다.
5. 기간 한정 현장 QR과 GPS 확인으로 스탬프 획득, 배지·XP·연속 방문 기록을 갱신한다.
6. 매일/매주 쿠폰을 수집해 상인 화면에서 대면 사용 처리한다. 실제 지급 조건과 환불·오발행 대응은 상점별 약관 필요.

### 디자인 규칙

- 놀이공원식 테마 구역: 🐠 수산랜드 / 🍓 과일정원 / 🥩 식재료광장 / 🍱 테마푸드관.
- 미션은 **발견/방문/다양한 동선** 중심. 유료 랜덤박스나 경제적 확률형 뽑기는 사용하지 않는다.
- AR 정보는 교차로 보행 중 주의를 분산시키지 않아야 한다. 정지 후 촬영/확인 경고, 차량·상하차 구역 위험 안내 필요.
- 상점·광고 추천 순위가 광고비로 바뀌면 광고/스폰서 표기 및 신뢰성 보호 필요.

## 기술 아키텍처

`Google Maps 2D/3D v2 지도` ← 점포대장(SQLite) → `AR 카메라 UI (BarcodeDetector / ORB)` → `QR+GPS 인증 게이트` → `방문/XP/배지` → `기간별 쿠폰 발행/지갑/상인 사용` → `메뉴/블로그/정식 배달파트너 URL`.

- V3 `server.py`는 V2 `registry_server.py`의 점포 등록·Google 지도 API를 계승한다.
- 서버가 원시 GPS를 방문 DB에 보관하지 않도록 설계했다. 단, 웹 서버/프록시 접근 로그·통신사업자의 부가 로그 정책은 별도 관리해야 한다.
- 신뢰할 수 없는 상점 이미지 자동 인식: ORB 기준 사진 데모(단일 기준 사진). 실제 현장 상호 판별에는 다면/조명/계절 변화, 간판 교체, 혼동 행렬 평가가 필요하다.
- 상인 QR: 짧은 유효시간 + 서버 서명 + 매장 GPS 반경 + 위치 정확도 요구. 실제 운영 시 3자 도용·원격 QR 중계·GPS 위변조에 대한 추가 방어 필수.

## 4개 핵심 사업 모델

- **현장 광고 상품:** 스폰서 탐방 미션, 구역 상단 추천(광고 표시), 블로그와 숏폼 소개 슬롯.
- **상인 SaaS:** 메뉴판 사진·블로그·QR·일간 쿠폰/주간 쿠폰 발행, 방문/쿠폰 사용 통계 대시보드. 베타에서는 통계 시각화/상용 결제 미구현.
- **관광·지역 이벤트:** 가락시장 스탬프 투어, 새벽시장 체험, 제철 푸드 페스티벌, 시장 해설.
- **배달/포장 전환:** 공식 주문 사이트 링크 → 제휴 API 연동 → 결제/배송 SLA/취소·반품 → CS. **베타는 요청 기록만.**

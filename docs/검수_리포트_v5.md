# 가락랜드 MARKET GROWTH v5 — 비판적 검수 보고서

## 구현 범위 및 강점

- 기존 가락랜드 AR·지도·쿠폰 탐험 시연 프로그램과 하나의 Python 서버에서 통합 동작.
- 새 고객 페이지: AI 식재료 사진 + 4개 품목 샘플 특가 + GPS 검증 여부 표시 + 쿠폰 수령 + Google 지도 길찾기.
- 쿠폰: 세션 ID별 1회 발급, 재고 한도, 예정/종료 시각 판정, 매장별 상인 키 사용 승인, 중복 사용 차단, 발행 중지.
- 상인 관리: 전체 점포 등록 목록에서 매장 선택, 신규 특가 예약·중지, 매체별 광고 캠페인 예약·취소, 현장 사용 확인, 승인된 가맹점 모의 상품권 차감.
- 연합 시연권: 권면 3만/5만/10만 원, 할인된 가상 구매가, 세션별 카드, 16자리 시연 확인코드(해시 검증), 원장, 멱등 요청, 잔액 부족 및 중복 승인 방지, 관리자의 사용 거래 1회 취소.
- 마케팅: 매체별 광고 동의 및 철회(자기 등록), 수신자 대상 중복 제외, 예약 모의 발송, 전송 결과 카운트, HMAC 서명 수신거부 링크, SMTP/SOLAPI 요청 생성 코드(실발송 기본 차단).

## 수치가 있는 검증

- 37개 Python 단위/서버 통합/기존 코드 회귀 검사 **통과** (`docs/v5_final_tests.log`).
- Chromium 실제 화면 검수: 1440×900 PC, 390×844 모바일. 브라우저의 로컬 API 직접 연결은 환경에서 차단되어, 로컬 Python HTTP 서버와 실제 요청을 교환하는 Bridge를 이용함. 4개 고객 화면, 쿠폰 수령/지갑 전환, 수신 동의 입력, 상인 화면 이동 시 **JS 오류 없음, 가로 넘침 없음** (`docs/v5_browser_offline_test.log`).
- 생성된 이미지 및 스크린샷은 `assets/v5/`와 `v5_*.png`에 포함.

## 발견한 결함 및 수정

1. 이메일 주소와 이메일 광고 수신동의가 같은 필드명으로 충돌 → `email`/`emailOpt` 분리.
2. 브라우저 타임존과 KST 일정 필드 충돌 → 브라우저 ISO UTC 오프셋을 서버에서 KST로 정규화.
3. 상품권 번호만 있으면 사용할 수 있던 설계 위험 → 16자리 확인코드와 서버 측 해시 검증 추가.
4. 이미 첫 특가를 등록한 점포만 상인 드롭다운에 표시 → 전체 등록 점포 선택 가능하도록 변경.
5. 광고 예약 및 특가 발행 후 취소가 없던 문제 → 상인 인증 후 예약 취소/특가 중지 API 추가.
6. 승인받지 않은 매장의 상품권 사용 위험 → 가맹 승인 레지스트리 강제 검증.
7. 실발송 오인 위험 → 브라우저 및 API 응답에 모의 발송/실결제 불가 표시하고 기본 차단.

## 남은 운영 차단 요건

- 가락시장 상인 연합회의 실제 승인·상표 사용·상거래 규약 및 공동 가맹 계약.
- 금융업 등록 여부 및 면제 요건·충전금 보호·기한·환불정책·정산 정책 법률 검증.
- PG 결제 및 실제 매입 확정(Webhook) 전에는 금전성 잔액 발행 절대 금지.
- 제휴 공급사 발신번호·카카오 채널 및 광고 발송 자격/수신거부/야간 제한/개인정보 암호화·삭제.
- 상인 현장 계약/실명 검증/점포대장·위성 실측 좌표·실내 호실 도면.
- 네트워크를 통한 실Google 지도 렌더·모바일 실GPS·실PG·실발송/발송 실패 및 공급사 피드백은 이번 검수에서 수행하지 않음.

**납품 판단:** 실제 돈·실광고 없는 통합 기능 검증용 **베타 패키지**. 금융/마케팅 상용 서비스로 직접 공개할 수 있는 완성판은 아님.

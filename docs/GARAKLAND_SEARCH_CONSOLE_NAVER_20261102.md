# 가락랜드 구글·네이버 검색 등록 준비 · 2026-11-02

대상: https://garakland.lexid.site/

코드 작업: robots.txt, sitemap.xml (8개 공개 페이지), 주요 페이지 canonical 및 고유 description, 공개 메인 페이지의 HTML 본문, 검수 전 화면 noindex.

**소유권 등록/색인 제출은 아직 미완료**. Search Console 및 네이버 서치어드바이저 계정에 접근해 소유확인 코드를 받아야 하며, 등록만으로 색인이 보장되지 않음.

구글: https://search.google.com/search-console → 'URL 접두어' → https://garakland.lexid.site/ → 'HTML 태그' 인증 → 사이트맵 sitemap.xml 제출.
네이버: https://searchadvisor.naver.com/ → 웹마스터도구 → 사이트 추가 https://garakland.lexid.site → HTML 태그 인증 → 사이트맵 https://garakland.lexid.site/sitemap.xml 제출.

사이트 소유권 인증태그는 **각 서비스가 계정에 발급한 실제 값**만 사용. 임의 토큰 사용 금지.

주의: 가락랜드는 롯데월드와 공식 제휴 또는 공동 홍보 중인 것으로 표시하지 않음. 도면은 정확한 실측 도면이 아님.

# GARAKLAND STUDIO v4 — 디자인 시스템·페이지별 비판 검수

- 제작: 2026-10-29
- 근거 코드: GARAKLAND v3.1 Coupon Google NAV (v3.1 서버·DB·API 유지)
- 분류: UI·UX 및 신규 프런트엔드 기능을 통합한 **베타**. 실제 점포 전수 좌표, Google Cloud 실계정, 현장 QR/GPS 및 배달·결제망은 검증 대상에서 제외.

## 설계 원칙

1. **목적 우선:** 쿠폰 수령 → 매장 정보 → Google 지도에서 길찾기 → 현장 제시 단계를 최우선.
2. **진짜와 시연 분리:** 가상 상점, AI 사진, GPS 미검증, 실제 주문 불가를 숨기지 않음.
3. **상인 친화:** 운영자는 사진·블로그·메뉴·캠페인을 한곳에서 등록하며 프로필 완료 기준을 확인.
4. **모바일 가독성:** 큰 터치 영역, 고대비 진녹색 CTA, 짧은 설명 및 하단 내비게이션.
5. **지도 유연성:** Google API 키가 없으면 기존 모식도, 승인 좌표가 없으면 시장 공통 길찾기.

## 중요 리스크 및 비판적 판단

### 1. 현장 안내의 정확도
- 공식 점포 배치도와 점포 정보는 수시 변경될 수 있으므로 운영 전에 최신 자료, 실내 호실 도면 및 좌표 검증이 필요.
- Google 지도 길찾기는 실내 호실까지의 단계별 안내를 기본 제공하지 않음. 검증된 개별 좌표만 매장 GPS로 안내하고 나머지는 시장 공통 위치.
- GPS 실내 반사/오차와 카메라 인식 오류에 대한 현장 테스트 필요.

### 2. 시연 이미지·브랜드 검증
- 생성 사진 6종은 **AI 기획 시연 이미지**이며 가락시장의 실제 매장·상인을 촬영한 것이 아님.
- `editorialPhoto()`는 시연 점포에만 AI 이미지를 사용하고, 실제 등록 매장은 업로드된 대표 이미지를 우선 사용.
- 실재 상호와 상인 홍보 사진/메뉴판/브랜드 로고는 소유자 동의 및 정확한 최신 정보로 교체해야 함.

### 3. 안전 및 비즈니스
- 공유 링크는 현재 접속한 도메인에 매장 ID를 부착; 실제 배포 도메인과 HTTPS 필요.
- 관심 매장은 브라우저 localStorage에만 저장; 회원 간 동기화가 아님.
- v3.1의 관리자 토큰·상인 비밀키 설계는 기술 베타 수준. 상용 서비스에는 정식 계정/역할 정책/감사로그/로그인 제한/권한 검증이 필수.
- GPS 개인정보 및 위치기반서비스 동의·보호 정책, 사진 업로드 동의, 배달 제휴, 모바일 앱 스토어 정책 별도 검토 필요.

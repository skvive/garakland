# 가락랜드 STUDIO v4.0 — 사진 중심 디자인 업그레이드

**이번 ZIP은 기존 v3.1 기능을 그대로 포함한 전체 프로젝트 소스입니다.**

## 바로 실행 (Windows)

1. 압축 해제 → `start_windows.bat` 실행
2. Python 3.10 이상 설치 필요. 브라우저에서 `http://localhost:8769` 접속
3. 상단/좌측 메뉴를 통해 `AR 탐험 / 지도·매장 찾기 / 미션 / 쿠폰 / 메뉴·주문 / 테마 가이드 / 상인 관리` 이동
4. 지도는 좌측 `지도·매장 찾기` → `Google 위성·지형·3D 지도` 에서 진입. 실제 Google Maps는 API 키 필요.
5. 카메라 실행이 어렵다면 `카메라 탐험 시작` → 점포 ID에 `GARAKLAND:demo-sea`를 입력해 기본 동선을 시험 가능.
6. 쿠폰 화면에서 **쿠폰 받기 → 매장 안내 창 → Google 도보 길찾기**를 눌러 동선을 확인하세요. 가상 매장은 시장 공통 위치로 안내합니다.

## 이번 버전의 변화

- 생성 AI 사진형 이미지 6종, 메인 에디토리얼 히어로, 3개 시장 구역 사진 카드
- 사진 썸네일 매장 목록, 빠른 업종 필터, 즐겨찾기(localStorage), 링크 공유
- 쿠폰과 실제 길찾기 동선을 시각적으로 강하게 연결
- 추가된 **테마 가이드북**: 챕터별 사진 + 해당 업종 매장 찾기
- 상인용 등록 체크 배지(메뉴·대표사진·메뉴판·블로그·GPS)
- 앱 전체 PC/모바일 간격·색·글꼴 개선, 키보드 `/` 로 검색
- 기존 AR·스탬프·쿠폰·주문 시연·상인 API·Google 2D/3D 지도 코드 유지

## 파일 탐색

- `index.html`: 전체 프런트엔드 앱
- `map.html`: Google 지도 페이지
- `game/studio.css`: 새 디자인 레이어
- `game/app.js`: 업그레이드 기능 + 기존 엔진
- `assets/editorial/`: AI 이미지 및 재사용 가능한 사진 컷
- `design_gallery.html`: 페이지별 PC·모바일 시연 캡처 갤러리(브라우저로 직접 열기 가능)
- `docs/디자인_페이지별_검수_v4.md`: 페이지별 비판 검수 및 상용화 전 남은 과제
- `tests/test_studio_browser.py`: 페이지별 브라우저 자동 UI 테스트

## 반드시 구분할 점

- **AI 생성 이미지**는 가락시장 또는 입점업체의 실제 기록사진이 아닙니다.
- 앱 기본 점포 4곳은 **가상 시연점**입니다. 임의 상호·사진·호실을 진짜로 표시하지 않습니다.
- 서버 API 자동테스트와 브라우저 모의 테스트는 통과했지만 실제 Google 3D GPU 렌더, 실매장 사진 인식, 상용 배달/결제는 현장 검증 전입니다.
- Google 지도 외부 길찾기 링크 자체는 키 없이 사용 가능합니다. 서비스에 내장하는 지도는 Google Cloud API 키·과금 설정이 필요합니다.

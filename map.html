GOOGLE MAPS CONNECTION

실제 지도를
연결하세요.

Google Maps JavaScript API 키를 연결하면 실제 위성·지형 지도와 3D 지형을 활용할 수 있습니다. 프로덕션(garakland.lexid.site)에서는 서버에 등록된 키가 자동 연결됩니다. 수동 입력 시 키는 현재 브라우저 탭 세션에만 저장됩니다.

Google Cloud에서 Maps JavaScript API 활성화, 결제 설정, HTTP 리퍼러 제한을 구성하세요. 운영용 도메인은 HTTPS를 권장합니다.

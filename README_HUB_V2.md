# 가락한상 모듈형 통합 운영 허브 v2.0

**실행 가능 베타 패키지** — v1 브랜드 홈페이지 및 이전 가락랜드 지도/AR/쿠폰/상품권/ERP 시연 코드를 보존한 새 운영 관리판입니다.

## Windows 원클릭 실행

1. ZIP 압축 해제 → Python 3.10 이상 설치
2. `RUN_HUB_WINDOWS.bat` 더블클릭
3. 콘솔에 표시되는 **LOCAL ADMIN TOKEN**을 복사
4. 브라우저 `http://localhost:8769/hub.html` 접속 → 토큰 입력 → 연결
5. 모듈 카드·통계·검수 작업·출시 체크리스트·감사로그 확인

`RUN_HUB_TESTS_WINDOWS.bat`: 전체 Python 테스트 실행. 실패가 있다면 배포하지 마세요.

Mac/Linux: `sh RUN_HUB_MAC_LINUX.sh` → 같은 주소. Python 3.10+ 필요.

## 핵심 기능

- 12개 기본 모듈(점포·지도·AR·상품 ERP·쿠폰·상품권·주문·마케팅·상인·운영 ERP·브랜드 콘텐츠·통계)을 통합 관리
- 신규 **연결형 모듈 등록**(기존 내부 HTML 페이지를 운영 카드로 추가, 임의 코드 실행 불가)
- 모듈 상태 변경/선행 모듈 확인, 매핑된 기존 API 접근 제어, 서버 변경 이력
- 7·14·30·90일 쿠폰·방문·주문 통계, 실점포 검증과 시연 점포 분리 표시
- 통계 스냅샷·쿠폰 중복 검수·출시 검토·마케팅 동의 집계 수동 예약/실행, 감사 추적
- 기존 8개 가락한상 브랜드 페이지, 가락랜드 v7, ERP·문서·사업계획·브랜드북 보존
- PC 1440 / 모바일 390 오프라인 Chromium UI 검사 이미지 포함

**중요:** 기본 12개 모듈 관리와 연결형 모듈 추가는 동작하지만, 새 기능 코드를 사용자가 입력만 하면 자동으로 생성·배포되는 플러그인 실행기는 아닙니다. 연결형 신규 모듈은 HTML 링크/관리 상태만 등록됩니다.

## 구성 파일

- `hub.html`: 관리자 허브 화면
- `hub/core.py`: 신규 v8 API/SQLite 스키마/의존성·통계·검수 로직
- `hub/app.js`, `hub/style.css`: 디자인/사용자 조작
- `server.py`: v8 API 라우팅과 기존 기능 연동 및 모듈 중지 게이트
- `docs/v8/백엔드_상세설계_모듈허브.md`: 전체 기술 설계도/ERD/운영 및 배포 한계
- `docs/v8/TEST_RESULTS_FULL.log`: 97개 Python 테스트 기록
- `docs/v8/BROWSER_QA.json`: Chromium 오프라인 브라우저 검사 기록
- `docs/v8/hub_*_dashboard.png`, `hub_*_modules.png`, `hub_*_analytics.png`: 페이지 이미지
- `tests/test_hub_v8.py`: v8 API·통합 테스트 31개

## 실행 시 주의

- 콘솔에서 자동 생성된 토큰을 외부에 공개하지 마세요.
- 샘플 상점과 가격·쿠폰·매출·방문은 시연 데이터입니다.
- Google 지도 실SDK, GPS 실측 및 AR 현장 품질, 실제 결제·송금·충전, 광고 대량발송을 자동으로 활성화하지 않습니다.
- `GARAK_DB_PATH` 환경변수로 SQLite 위치를 변경할 수 있습니다. 기본 DB는 실행 시 `data/garakland.sqlite`에 신규 생성됩니다.
- 서버는 기본 로컬호스트에서만 열립니다. 외부 접속 전에는 HTTPS, 인증·권한 및 보안 진단이 필요합니다.

## 현재 테스트와 상용화 한계

통합 테스트 97개 + PC/모바일 오프라인 브라우저 모의 API 검사는 통과. **실환경 Google Maps SDK, 실제 상점 전수 좌표, 배달 연동, 카카오/SMS, 실결제·선불 상품권, 다중 사용자 인증, 부하 및 현장 AR은 미완료**입니다. 따라서 상용 서비스 운영판이 아닌 기능형 관리자 **베타**로 제공됩니다.

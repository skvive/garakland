# 가락한상 브랜드 사이트 v1.0 — 2026-10-29

## 빠른 실행

Windows: `RUN_BRAND_WINDOWS.bat` 더블클릭. Python 3.10+ 필요. 웹브라우저에서 `http://localhost:8769/` 실행.
Mac/Linux: `./RUN_BRAND_MAC_LINUX.sh` 실행 후 같은 주소 접속.
테마 미리보기만 할 경우 `index.html`을 로컬 파일로 열 수 있으나 **API·상인 ERP·기존 AR 기능은 서버 실행이 필요**합니다.

## 기존 실행 코드 유지

이 패키지는 과거 가락랜드 v7 실행 소스를 바탕으로 **원래의 API·SQLite·AR·마케팅·ERP 코드를 유지**하며, 브랜드 디자인 전용 사이트를 덧붙였습니다.
- `ar-quest.html` 기존 AR 탐험 프런트
- `market.html` 기존 특가·쿠폰·연합 시연권·상인 마케팅
- `map.html` 기존 Google Maps 2D/3D 선택·점포 등록 엔진(별도 API키 필요)
- `ops.html` 기존 ERP 운영센터
- `server.py`, `market/`, `ops/`, `game/`, `src/`, `tests/` 등은 v7 원본 기능
- `brand/`는 신규 가락한상 브랜드 디자인·데이터·테스트
- `assets/brand/`는 사용자가 제공한 원본 이미지와 편집 적용 자산
- `brand_strategy_docs/`에는 기존 사업계획서·투자제안서·브랜드북·등록 준비서류의 HTML/PDF가 포함됨

## 콘텐츠 및 법적 주의

1. `brand/data.js`의 4개 상점과 모든 메뉴·가격·쿠폰은 **시연 가상 데이터**입니다. 실제 가락시장 점포, 실거래 가격, 영업시간 또는 유효 혜택이 아닙니다.
2. 테마 구역 지도는 실측 자료가 아닌 시각적 길잡이입니다. Google 지도 길찾기는 별도 검증 GPS가 없으면 **가락시장 공통 목적지**까지만 연결합니다.
3. 상용 Google 위성·3D 지도, AR 카메라, 지리정보, 상품권 충전, 실결제·실발송은 별도 API·사업자 승인·상인 계약·현장 확인이 필요합니다.
4. 마스코트와 엠블럼은 **사용자가 제공한 원본 이미지**입니다. 저작권·상표 사용 권한과 AI 생성물의 권리관계가 별도 확인되어야 합니다. 기존 코드의 MIT 라이선스가 모든 이미지 사용 권리까지 보증하는 것은 아닙니다.
5. 가락한상과 가락시장 공식 운영기관의 제휴·공인 여부는 확인되지 않았으며, 본 버전은 독립 베타·브랜딩 프로젝트입니다.
6. 프런트 쿠폰·찜·장바구니·상인 신청 시연은 브라우저 `localStorage`에 저장되며 실제 계정/결제/관리자 DB에 등록되지 않습니다. 실제 상용 운영 시 서버 기반 인증, 개인정보 및 동의 처리로 교체해야 합니다.
